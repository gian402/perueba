## Navigation

This project uses [Navigation 3](https://developer.android.com/guide/navigation/navigation-3),
the modern Compose-first navigation library.

Navigation is modelled as a plain `mutableStateListOf<Any>` back stack. Each
destination is a Kotlin data object or data class (the route key). `NavDisplay`
watches the back stack and displays the matching composable via `entryProvider`.

```kotlin
// Push a new destination (navigate forward)
backStack.add(ProfileDest)

// Pop the current destination (navigate back)
backStack.removeLastOrNull()
```

Route destination keys are declared alongside their composables. Generated
screens receive `backStack` via a lambda parameter so navigation can be
triggered from anywhere inside the screen.
